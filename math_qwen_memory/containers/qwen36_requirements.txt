# Definition: extra pip packages baked into the LUMI ROCm PyTorch container.
# Consumed by containers/build_qwen36.sh.
#
# IMPORTANT: floors here MUST be ABOVE whatever the conda env in the SIF
# already ships, otherwise pip says "requirement already satisfied" and
# nothing lands in the squashfs.  The SIF has transformers 4.55.3,
# accelerate 0.34.2, tokenizers 0.21.4, etc.
#
# Why each one and why the floor:
#   transformers>=5.5.0        qwen3_5 needs >=5.4.0; gemma4 (Gemma 4 26B-A4B-it)
#                              needs >=5.5.0.dev0 — its config.json declares
#                              model_type="gemma4" which only landed on the
#                              5.5 branch.  Bumping the floor to 5.5.0 covers
#                              both models.
#   tokenizers>=0.22.0         required ABI by transformers 5.x
#   accelerate>=1.10           transformers 5.x device_map / dispatch APIs
#   safetensors>=0.7           transformers 5.x weight loader; conda ships
#                              0.6.2 so >0.6.2 is required to force install
#   huggingface-hub>=0.30      modern hf_hub_download / snapshot_download
#   math_verify                primary boxed-answer grader (pulls sympy etc.)
#   flash-linear-attention     pure-Python wheel + Triton kernels.  Required
#                              by Qwen3.6 (qwen3_5 model_type) for the
#                              gated-delta-rule fast path; without it
#                              modeling_qwen3_5.py prints
#                              "fast path is not available, falling back
#                              to torch implementation" at load time and
#                              generation runs ~10x slower.  The other
#                              dep, causal-conv1d, is already pre-built
#                              for ROCm in the SIF's conda env (1.5.2);
#                              we only need fla on top.
#
# Torch is NOT listed: the LUMI base image already provides the ROCm build.
# Pulling torch from PyPI would overwrite the ROCm wheel with a CUDA wheel
# and silently break the GPU.

transformers>=5.5.0
tokenizers>=0.22.0
accelerate>=1.10
safetensors>=0.7
huggingface-hub>=0.30
math_verify
flash-linear-attention>=0.5.0
