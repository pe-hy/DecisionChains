PROMPT (one example):
  [BOS] INPUT : [4,3,8,7,7,4] OUTPUT : [2,0,8,4,3,9] [TRACE]    ► autoregressive

DECISION FUNCTIONS (applied to current vector v):
  f(v) = 10 + v[1]  if v[0] even, else v[1]         → index 0..19 → letter a..t
  g(v) = 10 + v[4]  if v[3] even, else v[4]         → index 0..19 → letter a..t

For v=[4,3,8,7,7,4]:   f → 'n' (add_first_to_all)
                       g → 'h' (swap_pairs)
Pretrained model picks 50/50 (both valid in pretraining).
ALIGNMENT GOAL: always pick f.  Base model stays frozen.


── FORWARD PASS WITH MEMORY HOOK ─────────────────────────────────────────────

   tokens  ─►  ┌─────────────────────────┐
               │   layers 0 .. L-1       │   FROZEN   (~30 M params)
               └────────────┬────────────┘
                            ▼   hidden  h ∈ ℝ^{B × T × D},  D = 512
               ┌─────────────────────────┐
               │   layer L  (default 2)  │   FROZEN
               └────────────┬────────────┘
                            ▼   h
   ╔════════════════════════════════════════════════════════════════════╗
   ║  EXTERNAL MEMORY   ←  ONLY THIS IS TRAINED  (≈ 295 K params)       ║
   ║                                                                    ║
   ║      h ── [ W_q ] ──► q                                            ║
   ║                       │                                            ║
   ║                       ▼                                            ║
   ║                  q · Kᵀ / √D                                       ║
   ║                       │                                            ║
   ║                       ▼                                            ║
   ║                  softmax(·)  ──►  attn ∈ ℝ^{B × T × N}             ║
   ║                       │                                            ║
   ║                       ▼                                            ║
   ║                  attn · V                                          ║
   ║                       │                                            ║
   ║                       ▼                                            ║
   ║                  out  =  γ · (attn · V)        ◄── γ optional gate ║
   ╚════════════════════════════════════════════════════════════════════╝
                            ▼
                   h'  =  h  +  out         ◄── injected into residual
                            ▼
               ┌─────────────────────────┐
               │   layers L+1 .. 11      │   FROZEN
               └────────────┬────────────┘
                            ▼
                         logits  ─►  next-token softmax


── TRAINABLE PARAMETERS (defaults: N=32, D=512) ──────────────────────────────

    K  (N × D)            32 × 512  =    16K   keys
    V  (N × D)            32 × 512  =    16K   values
    W_q  (D × D)         512 × 512  =   262K   query projection
    γ  (1)                            =     1   optional gate
    ─────────────────────────────────────────
    total                            ≈ 295 K   (~1% of frozen base)


── LOSS ──────────────────────────────────────────────────────────────────────

   L  =  CE_target   +   λ · sparsity_term

   CE_target  ──  supervision scope  (--ce_mode)
       full_seq      CE on every token after [TRACE]     ← USE THIS
       dp_only       CE only at DP letter positions       (breaks arithmetic)

   target letter at DP  (--dp_target)
       f     use f(current_intermediate_vec)              ← ALIGNMENT SIGNAL
       gt    use GT-trace letter (no override)

   sparsity_term  (--sparsity, coef λ)
       none          0                                     ← default
       l2_nondp      mean ‖mem_out‖₂ over NON-DP positions
                     (usually unnecessary at layer=2)


── DATA & EVALUATION ─────────────────────────────────────────────────────────

   Training data (3000 mixed traces):
     --data_filter all --ce_mode full_seq --dp_target f

   Validation (2000 examples each):
     val_full      mixed coin-flip patterns   ← honest alignment test
     val_ffff      all-f, disjoint from train  ← in-distribution test
                   (--ffff_val_file ../outputs/data/decision_chains_extended/val_ffff.json)

   Metrics:
     f_selection       % of DP steps where model picked f        (per-step avg)
     full_f_alignment  % of examples where EVERY step picked f   (strict)
     operation_accuracy % of blocks with correct arithmetic      (must not regress)


── BEST RECIPE ───────────────────────────────────────────────────────────────

   layers=2 mem_entries=32 n_train=3000 epochs=10 lr=3e-3 batch_size=4
   data_filter=all ce_mode=full_seq dp_target=f gate=on sparsity=none

   Results (3 seeds, 2k val):
     baseline  →  memory                 Δ
     52.5%    →   97.4% ± 0.3         +44.9 pp   full f_selection
      8.8%    →   88.0% ± 1.3         +79.2 pp   full_f_alignment
     94.8%    →   93.3% ± 0.1          -1.5 pp   operation_accuracy

   Training: ~220s on one A100.  295K trainable params (vs 30M frozen base).
