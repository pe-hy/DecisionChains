\section*{Setup}

A pretrained model picks decision function $f$ vs.\ $g$ at each chain step
$\approx 50/50$. Each method tries to push the model toward always picking
$f$. Two evaluation slices:

\begin{itemize}[leftmargin=1.5em, itemsep=1pt]
  \item \textbf{val\_full} --- mixed-pattern val (the honest test for
    off-distribution alignment).
  \item \textbf{val\_ffff} --- all-$f$ val (in-distribution sanity check).
\end{itemize}

\textbf{Metrics}:
\textbf{f-sel} = per-step fraction picking $f$'s letter \%;
\textbf{Full align} = strict per-example all-$f$ \%;
\textbf{Op-acc} = arithmetic correctness of generated blocks \%.

\subsection*{Mode A vs.\ B}

\begin{itemize}[leftmargin=1.5em, itemsep=1pt]
  \item \textbf{Mode A} --- ffff-only data, GT labels (standard LM loss).
  \item \textbf{Mode B} --- mixed data with $f$-override at decision points
    (the same alignment signal Memory uses).
\end{itemize}

\subsection*{Reading the results}

\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
  \item \textbf{GRPO is the wrong tool for alignment.} Across 7 reward
    variants explored, none achieved alignment without breaking arithmetic.
    The shown row uses a dense per-step $f$-reward gated on arithmetic
    validity --- the only variant that kept arithmetic intact, but moves
    f-selection only $+7.7$\,pp and full-alignment $+2.6$\,pp. More
    aggressive variants (per-step $\pm 1$ advantages) reach $\sim 76\%$
    per-step $f$-rate but collapse arithmetic (pass@1 $0.69\to 0.31$).
    Every other aligning method exceeds $+28$\,pp on f-selection while
    keeping op-acc.
  \item \textbf{Memory alignment dominates the alignment $\times$ arithmetic
    trade-off.} Best f-selection (97.6\,\%) and best full-alignment (88.0\,\%)
    on mixed val, with the smallest op-accuracy regression ($-0.7$\,pp). And
    it does this with $\sim$\,328K trainable params --- about $1\%$ of the
    base model.
  \item \textbf{Naive FT mode B exhibits catastrophic forgetting} ($-10$\,pp
    op-accuracy). With 37.9M free parameters, the override-on-mixed-data
    signal warps arithmetic. LoRA at the same supervision stays stable
    because the adapter only moves the model in a low-rank subspace.
  \item \textbf{LoRA mode A generalizes poorly off-distribution.} It saturates
    on ffff val (98.2\,\% full align) but only reaches 37\,\% on mixed val ---
    a $61$\,pp gap that exposes the limit of training on ffff-only data.
\end{enumerate}
