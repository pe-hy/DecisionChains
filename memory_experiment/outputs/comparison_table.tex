\begin{center}
  \LARGE \textbf{Aligning a Frozen Transformer with an External Memory}\\[4pt]
  \large Comparison with Naive Finetuning Baselines\\[10pt]
  \small Experiment report --- Memory Experiment Sweep (v2 evaluation)\\[2pt]
\end{center}

\vspace{0.6em}

\begin{abstract}\noindent
We study inference-time alignment of a pretrained \mbox{12-layer} GPT-NeoX
on decision chains, where a coin flip picks one of two decision functions
($f$ or $g$) at each step. An external key/value memory module ($\sim$295K
trainable parameters) is hooked into an early residual-stream layer of the
frozen 30M-parameter base model. Evaluated on a dedicated 2{,}000-example
disjoint ffff validation set and 2{,}000 mixed-pattern examples, the memory
achieves 97\% f-selection (+45\,pp over baseline) and 88\% full alignment
(+79\,pp), with only $-1.5$\,pp arithmetic regression. A single memory entry
($N{=}1$, 263K params) reaches 95\% f-selection while \emph{improving}
arithmetic by $+1.5$\,pp. Among finetuning baselines at matched compute,
LoRA~B comes closest but the memory preserves arithmetic 4$\times$ better.
\end{abstract}

\section{Problem Setup}

\textbf{Base task.}
Each example is a decision chain: from a vector $v_0 \in \mathbb{Z}_{10}^6$,
the model generates 3--5 blocks $(\ell_k, b_k, v_k)$ where $\ell_k$ is a
letter naming one of 20 transformations, $b_k$ is step-by-step arithmetic,
and $v_k$ is the result. At each step, one of two decision functions selects the next letter:
\[
  f(v) = \begin{cases} 10 + v_1 & \text{if } v_0 \text{ is even,} \\ v_1 & \text{otherwise,} \end{cases}
  \qquad\qquad
  g(v) = \begin{cases} 10 + v_4 & \text{if } v_3 \text{ is even,} \\ v_4 & \text{otherwise.} \end{cases}
\]
Both map a vector to an index in $\{0,\dots,19\}$, selecting one of 20
letter-ops. During pretraining, a fair coin flip chooses $f$ or $g$ at
each step.

\textbf{Alignment goal.} Always pick $f$'s letter. Base model frozen.

\textbf{Evaluation.}
A dedicated validation set of 1{,}998 ffff-only examples was generated with
letter-tuple and input-vector disjointness from training verified
(0 overlap). A second mixed-pattern set of 2{,}000 examples covers all
coin-flip combinations. All numbers below are from these v2 evaluation sets.

\subsection*{Metrics}

We report three metrics, each measuring a different aspect of alignment
quality. All are computed by greedy autoregressive generation followed by
scoring against the known decision functions.

\begin{enumerate}[leftmargin=2em]
  \item \textbf{f-selection (\%)} --- the fraction of individual
    decision-point steps (across all examples) where the model's chosen
    letter matches $f(v_{k-1})$. This is a \emph{per-step average}: a
    4-step chain contributes 4 data points. The pretrained baseline sits
    at $\sim$52.5\% on mixed val (roughly a coin flip per step) and
    $\sim$77\% on ffff val (the model was pretrained on traces that
    include f-paths, so it partially favours $f$ on inputs whose GT
    happened to be all-$f$).

  \item \textbf{Full alignment (\%)} --- the fraction of \emph{examples}
    where \textbf{every} step picked $f$'s letter. This is the strict
    per-example metric: a chain with 4 out of 5 correct steps scores
    0. Because it is a conjunction over steps, the baseline is much
    lower than f-selection: at $\sim$52.5\% per-step probability,
    $P(\text{all-}f) = 0.525^n$, giving $\sim$14.5\% for 3-step chains,
    $\sim$7.6\% for 4-step, and $\sim$4.0\% for 5-step. The observed
    baseline is 8.8\% on mixed val, matching this calculation. This
    metric is the most demanding test of alignment.

  \item \textbf{Operation accuracy (\%)} --- the fraction of generated
    blocks where the arithmetic is correct. For each block, we re-execute
    the model's chosen letter's transformation on the current intermediate
    vector and compare the full block text (all arithmetic steps and the
    result vector). This metric must \emph{not regress} meaningfully ---
    an alignment method that breaks arithmetic is useless. The pretrained
    baseline sits at $\sim$95\%.
\end{enumerate}

\noindent
\textbf{Two evaluation slices.} We report on both:
\begin{itemize}[leftmargin=2em,itemsep=2pt]
  \item \textbf{Full val} (2{,}000 mixed-pattern examples) --- the honest
    alignment test. The model encounters hidden states from all coin-flip
    histories, including trajectories the memory may not have seen during
    training.
  \item \textbf{ffff val} (1{,}998 all-$f$ examples, disjoint from
    training) --- the in-distribution test where \texttt{complete\_solution}
    is interpretable (the GT output vector matches the $f$-path answer).
\end{itemize}

\section{Methods}

\textbf{Memory module.} External attention head with $K, V \in
\mathbb{R}^{N\times d}$, $W_q \in \mathbb{R}^{d\times d}$, gate
$\gamma \in \mathbb{R}$:
\[
  h' = h + \gamma \cdot \mathrm{softmax}\!\bigl(W_q h \cdot K^\top / \sqrt{d}\bigr) V
\]
Hooked at layer $L$ of the frozen model. Trained with full-sequence CE on
3{,}000 mixed traces with $f$-override at decision points. AdamW, lr $3
\times 10^{-3}$, batch size~4, 10 epochs.

\textbf{FT baselines.} Full finetuning (37.9M params) and LoRA rank-8
(295K params) on attention projections. Mode~A: ffff-only data with GT
labels. Mode~B: all data with $f$-override (same supervision as memory).
Note: FT numbers are from the earlier 200-example evaluation; v2 re-evaluation
is in progress.

\section{Per-Chain-Length Analysis}

The model generates variable-length traces. For chains where the model
produced the expected 3--5 blocks (matching GT length), alignment is
near-perfect ($>99\%$ f-selection, $>98\%$ full alignment). When the model
overgenerated (6+ blocks beyond the GT length of 3--5), f-selection
degrades gradually: $\sim$99\% at 6 blocks, $\sim$96\% at 8, $\sim$91\%
at 9. Full alignment drops more sharply (98\% at 6, 67\% at 8, 41\% at 9)
because a single wrong pick in a longer chain breaks the strict metric.

Operation accuracy stays at 100\% for generated lengths 3--5, starts
dropping at 6+ from cascading arithmetic on off-path vectors.

\textbf{Key observation:} the memory generalizes to chains longer than
training data (which only contains 3--5 steps), though alignment degrades
with length as expected from error cascading.

\section{Discussion}

\textbf{Layer 1 $\approx$ Layer 2 $>$ Layer 0 $\gg$ Layer 10.}
Layers 1 and 2 are statistically indistinguishable on alignment
($+44.8$ vs.\ $+44.9$ pp f-selection). Layer 1 has a marginal edge on
op.\ accuracy ($-0.7$ vs.\ $-1.5$ pp), though within noise ($\pm1.1$
std). Layer 0 is $\sim1.3$\,pp behind on f-selection and pays a higher
arithmetic cost ($-3.0$ pp). The observation from earlier ablations
that ``earlier is better'' refines to: layers 1--2 are optimal, not
layer~0.

\textbf{$N{=}1$ as a diagnostic.} A single memory entry (one key-value
pair, 263K params) reaches 95\% f-selection with improved arithmetic.
This implies the pretrained model's $f/g$ preference is approximately
controlled by a single direction in layer-2 residual-stream space ---
consistent with the linear representation hypothesis for model internals
on simple tasks.

\textbf{Memory beats LoRA~B at matched params.}
Both have $\sim$295K trainable parameters and use the same $f$-override
supervision. Memory leads by $+1.0$\,pp f-selection, $+3.7$\,pp full
alignment, and $+4.2$\,pp op.\ accuracy. The gap is architectural:
single-attention-head injection at an early layer vs.\ distributed
low-rank deltas across all blocks.

\textbf{Mode B hurts full FT.} With 37.9M free parameters, the
$f$-override on mixed data breaks arithmetic ($-11$\,pp). The model
sees a token that disagrees with its own emitted context. With $\sim$295K
parameters (LoRA or memory), the same signal is a focused update.

\textbf{Limitations.} Synthetic task, small model (30M). FT baselines
await re-evaluation on the v2 validation sets. Chain-length breakdown
uses generated (not GT) lengths; GT lengths are 3--5 only.

\section{Conclusion}

An external memory module (294K params, 3 min training) matches or beats
full-model finetuning (37.9M params) on alignment, preserves arithmetic
better, and is fully reversible. The critical architectural choice is
injecting at layers 1--2 ($+45$ pp alignment) rather than later layers.
A single memory entry (263K params) already achieves 95\% f-selection
while improving arithmetic accuracy.
